Neuromorphic Architecture

RISC-V based parallel processing elements for biologically inspired neural computation with low power consumption

Abstract

Neuromorphic architectures are hardware architectures that use the biologically inspired neural functions as the basis of operation. Information processing based on spiking neuron architectures have caught considerable attention in recent years due to its low power consumption compared to traditional artificial neural networks.

In this project, as the first stage, we are implementing parallel multiple processing elements based on RISC-V architecture to represent biological neurons. Single neurons can be implemented as a single processor with local memory access or since the spike time of biological neurons is in the millisecond order multiple neurons can be virtualized to a single processor.

At the second stage of the process, we are expecting to design encoders and decoders to benchmark the architecture by solving classical machine learning problems.

Project Overview

Biologically Inspired Computing

This project focuses on developing neuromorphic architectures that mimic the computational principles of biological neural networks. By leveraging the efficiency and adaptability of brain-inspired computing paradigms, we aim to create hardware systems that can process information with significantly lower power consumption than traditional computing architectures.

RISC-V Based Implementation

Our approach utilizes RISC-V architecture as the foundation for implementing parallel processing elements. This choice provides flexibility, scalability, and the ability to customize the instruction set for neuromorphic computing tasks. Each processing element can represent individual biological neurons or virtualize multiple neurons depending on the computational requirements.

Two-Stage Development Approach

The project is structured in two main stages:

  • Stage 1: Implementation of parallel RISC-V processing elements for neuron representation
  • Stage 2: Design of encoders and decoders for machine learning benchmarking

Technical Approach

Neuron Virtualization

Given that biological neurons operate with spike times in the millisecond range, our architecture supports virtualization where multiple neurons can be efficiently managed by a single processor. This approach optimizes resource utilization while maintaining the temporal characteristics essential for neuromorphic computation.

Memory Architecture

Each processing element is designed with local memory access capabilities, ensuring low-latency data retrieval and storage. This distributed memory approach aligns with the decentralized nature of biological neural networks and contributes to the overall energy efficiency of the system.

Spiking Neural Network Support

The architecture is specifically optimized for spiking neural networks (SNNs), which process information through discrete spike events rather than continuous signals. This event-driven processing model naturally leads to significant power savings, especially in scenarios with sparse neural activity.

Research Goals

Primary Objectives

  • Develop efficient parallel processing elements based on RISC-V architecture
  • Implement neuron virtualization techniques for optimal resource utilization
  • Create encoders and decoders for machine learning applications
  • Benchmark the architecture against classical machine learning problems
  • Demonstrate significant power savings compared to traditional neural networks

Expected Outcomes

The successful completion of this project will result in a novel neuromorphic computing platform that combines the flexibility of RISC-V architecture with the efficiency of biologically inspired computation. The platform will serve as a foundation for future research in low-power neural computing and provide insights into the practical implementation of large-scale neuromorphic systems.

Potential Applications

The neuromorphic architecture developed in this project has potential applications in various domains:

  • Edge Computing: Low-power neural processing for IoT devices
  • Autonomous Systems: Real-time decision making with minimal energy consumption
  • Sensory Processing: Efficient processing of visual and auditory signals
  • Brain-Computer Interfaces: Neural signal processing and interpretation
  • Robotics: Adaptive behavior and learning in robotic systems
